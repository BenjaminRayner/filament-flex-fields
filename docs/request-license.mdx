Answer a few questions to check your scope. Standard plan results include a direct purchase link; qualifying Free use needs no purchase. Sending an enquiry is optional and is useful for Custom rights or unclear cases.

Assess the functionality using FLEX, rather than every feature in the same Laravel application. A shared backend does not automatically make internal monitoring commercial; a staff-only panel does not exempt product configuration. [See examples before answering](/docs/licensing#internal-panel-and-commercial-product-in-the-same-application).

Already know your plan? [Buy a standard license](https://shop.bjanczak.com/checkout/buy/9035f5b4-c5a2-4b03-867d-109b48d49134) and select the matching plan in checkout.
