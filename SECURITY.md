# Security Policy

## Supported Versions

Security fixes target the latest supported patch release. Upgrade to that patch
before reporting an issue where possible.

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | Security updates for the latest 4.x patch |
| 3.x     | Security updates for the latest 3.x patch |
| < 3.0   | No longer supported |

## Reporting a Vulnerability

Email `barek122@gmail.com` to report a suspected vulnerability privately. Do not
open a public issue or pull request containing vulnerability details or an exploit.

Include the affected package version, PHP/Laravel/Filament versions, the impact,
and minimal reproduction steps. Remove credentials, personal data and other secrets.

Reports are reviewed privately. Once a fix is ready, we coordinate disclosure
and publish the affected versions, upgrade instructions and an advisory where
appropriate. Reporter attribution is included only with their consent.
